# Компоненты-кандидаты для UI Kit

Этот реестр относится только к новым универсальным компонентам прототипа «База знаний». Интеграционная обвязка сервиса и локальное продуктовые меню сюда не входят.

## KnowledgeGroupAccordion

- **Назначение:** раскрываемая группа знаний в профиле компании.
- **Почему не используется текущий Accordion UI Kit:** его визуальная модель и структура заголовка не поддерживают нужную композицию профиля — заголовок 20 px, описание, счётчик фактов, статус, источники и круглый шеврон.
- **Контракт:** группа данных, начальное состояние, открытие источников, действие через чат и фокусировка конкретного знания.
- **Состояния:** закрыт, открыт, сфокусировано связанное знание, пустые источники, предупреждение и недостаток данных.
- **Доступность:** нативная кнопка заголовка, `aria-expanded`, `aria-controls`, видимый `focus-visible`; вложенные действия не помещаются внутрь кнопки заголовка.
- **Адаптивность:** двухколоночные атомарные значения переходят в одну колонку до 850 px.
- **Токены:** цвета, поверхности, границы и состояния берутся только из семантических переменных UI Kit.
- **Перед переносом в UI Kit:** стабилизировать типы статусов, добавить публичный слот метаданных, проверить анимацию раскрытия и покрыть интерактивными тестами.

## CircularProgress

- **Назначение:** компактное круговое отображение процента покрытия.
- **Почему нужен отдельный компонент:** существующая диаграмма UI Kit не позволяет одновременно свободно менять размер и толщину кольца в компактных карточках профиля.
- **Контракт:** `value`, `size`, `thickness`, семантический вариант, доступное название и показ числового значения.
- **Состояния:** success, warning, danger, neutral; значения ограничиваются диапазоном 0–100.
- **Доступность:** SVG имеет роль изображения и локализованное доступное название.
- **Адаптивность:** размер принимает число или CSS-значение, геометрия пересчитывается через единый viewBox.
- **Токены:** цвета трека и значения берутся из семантических переменных UI Kit.
- **Перед переносом в UI Kit:** согласовать названия вариантов, минимальные размеры и поведение подписи при размере меньше 32 px; добавить визуальные тесты.

## Возможный кандидат: SourceTags

Компонент пока не считается готовым кандидатом. Сначала нужно стабилизировать модель типов источников, состояния переполнения и контракт открытия Drawer. После этого можно оценить, является ли он общим компонентом или остаётся предметным компонентом Базы знаний.

## Критерии готовности кандидата

1. Публичный API не зависит от данных конкретного сервиса.
2. Все визуальные значения используют токены UI Kit.
3. Все пользовательские строки передаются снаружи или локализуются.
4. Описаны состояния loading, empty, error и disabled, если они применимы.
5. Пройдены клавиатурные сценарии и проверка доступных названий.
6. Есть unit-тесты поведения и визуальные примеры всех состояний.
7. Зафиксировано отличие от существующего компонента UI Kit и план совместимости.
